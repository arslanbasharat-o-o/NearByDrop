# Reporting a security issue

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/arslanbasharat-o-o/NearByDrop/security/advisories/new). Include the affected version, reproduction steps, and impact. Do not publish private keys, personal files, or live pairing codes.

Security fixes target the latest release. Wireless device trust does not verify a Google account. Use manual consent on untrusted networks. See the README for current release and network limitations.
