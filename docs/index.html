Nearby Drop: Quick Share for Mac
Two-Way Android File Transfers.

Nearby Drop by Arslan Basharat is an independent macOS menu bar app for two-way Quick Share file transfers: send from Mac to Android and receive from Android on Mac. It also sends to and receives from compatible Windows Quick Share clients; both directions passed in a Debug test with one PC, while the packaged release was not separately device-tested. Use USB MTP to browse Android storage, share through Finder, or exchange Quick Share QR codes. // 01 THE NEARBY DROP TOOLKIT

More than wireless file sharing

A Mac menu bar app for nearby transfers, USB file management, QR workflows and Finder sharing. Compatibility and test coverage are called out where they matter.

[ ANDROID ↔ MAC ]

Two-way Quick Share

Send files from the Mac to compatible Android devices, or receive Android files on the Mac. Review incoming requests and confirm the matching PIN; trusted devices can be auto-accepted. The regular device-list flow uses a reachable local network.

[ WINDOWS ↔ MAC ]

Windows Quick Share

Send to or receive from compatible Windows Quick Share clients while Nearby Drop runs on the Mac. Both directions passed with one PC in a Debug test; the packaged release was not separately device-tested.

[ QR SHARE + SCAN ]

QR tools in the app

Show a Mac-generated Quick Share code for Android, or scan an Android code with the camera inside Nearby Drop. Both QR directions passed with a Pixel 8 Pro; Android-to-Mac receiving passed during v2.3.2 validation.

[ ANDROID ↔ MAC · USB ]

Android USB file browser

Browse phone storage over MTP, drag in or choose Mac files to upload, download selected items or whole folder trees, and save a file to a chosen Mac location. Physical Pixel and Nexus browse, upload and download checks passed.

[ FINDER SHARE MENU ]

Share straight from Finder

Use macOS’s Share menu to send files, folders or web links to a nearby Android device, without first opening the main transfer flow.

[ TRANSFER CONTROLS ]

Progress, cancel and history

Choose several files or folders, drag items into the app, follow transfer progress and available speed or time estimates, cancel an active transfer, and review recent transfers or reveal saved files in Finder.

[ MENU BAR PREFERENCES ]

Make it fit your Mac

Rename the Mac as nearby devices see it, choose where received files are saved, auto-accept transfers from trusted devices, launch at login, choose light, dark or system appearance and an accent or menu bar icon, and turn transfer sounds or haptics on or off.

Wireless speeds vary with the devices and network. See the transfer status table below for the tested directions and current limits.

// 02 WIRELESS AND USB SETUP

Choose a transfer method

Nearby Drop requires macOS 14 or later. Quick Share compatibility and wireless discovery can vary by device and network.

REQUIREMENTS: macOS 14+; Android Quick Share availability varies by device SPEED: DEPENDS ON YOUR NETWORK

Send files over a shared local Wi-Fi network:

  1. Connect your Mac and Android phone to the same reachable local Wi-Fi network.
  2. Open Nearby Drop from the Mac menu bar and allow local network access if macOS asks.
  3. Select files on Android and open Share → Quick Share.
  4. If Nearby Drop appears in the device list, select it and confirm the matching PIN on your Mac.
  5. If discovery fails, check the network notes below or use USB MTP. QR workflow status is listed below.
// 03 PROTOCOL ARCHITECTURE

How Android Quick Share Works with Nearby Drop

Nearby Drop is an independent implementation of the Nearby Share / Quick Share transfer protocol. It communicates with compatible Android devices over the local network.

[ 01 / DISCOVERY ]

mDNS Beacon

Nearby Drop advertises its service over local multicast DNS. When both devices can reach one another and network discovery is allowed, the Mac can appear in Android’s Quick Share sheet.

DISCOVERY: Zero Cloud Servers
[ 02 / HANDSHAKE ]

UKEY2 Verification

The UKEY2 handshake uses Elliptic Curve Diffie-Hellman (P-256). A matching confirmation PIN helps users verify the pairing before accepting files.

SECURITY: ECDH P-256 + HKDF
[ 03 / TRANSFER ]

Direct TCP Sockets

File data streams over the local network rather than a cloud relay. Throughput depends on the phone, Mac, signal strength, router, and network configuration; no fixed speed is promised.

THROUGHPUT: NETWORK DEPENDENT
[ 04 / PERSISTENCE ]

Native Finder Save

Transferred photos, 4K videos, and zip files are written directly into your ~/Downloads/ directory. An alert sound plays with a one-click button to reveal files in Finder.

DESTINATION: Direct to Downloads

Android Quick Share and Mac file transfers

Nearby Drop is an independent macOS menu bar app for Android Quick Share (formerly Nearby Share), USB MTP file browsing, and Finder sharing. Android-to-Mac and Mac-to-Android wireless transfers use a reachable local network. QR receiving and Windows workflows are shown with their current test status below.
Some Android phones can send to a Mac through Google's native Quick Share and Apple's AirDrop interoperability. Check Google's current Quick Share compatibility guide. Nearby Drop is an independent Mac menu bar option for Android Quick Share; on compatible devices, select files on Android, open Quick Share, and choose the Mac if it appears. Device support and local-network discovery vary.
There is no single speed guarantee. Results depend on the phone and Mac radios, signal, router, cable, storage, and network settings. A 5 GHz network may help when both devices and the router support it.
The current download is ad hoc signed and not notarized, so macOS may show a Gatekeeper warning. Review the public repository and release details before installing. If you choose to run it, use Finder's Control-click → Open flow or the macOS System Settings → Privacy & Security → Open Anyway control.
It is designed for Android devices that provide Quick Share, but compatibility can vary by phone, Android version, and network. A Pixel 8 Pro has been tested on a local network; every model and network combination has not been verified. LTE-only phone-hotspot discovery is a known unverified case.
Two-way Windows Quick Share is included in the current v2.3.4 release. Both directions passed in a final Debug test build with one Windows PC; the packaged release was not separately device-tested. Nearby Drop runs on the Mac, and broader Windows device testing is still limited.
The in-app camera scans Android-generated Quick Share codes. Android-to-Mac receiving passed with a Pixel 8 Pro during v2.3.2 validation and is included in the current release. Mac-generated QR sending is a separate direction and passed with a Pixel 8 Pro.
