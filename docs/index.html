Frequently Asked Questions

Everything you need to know about Nearbydrop.

Can I AirDrop files from Android to Mac?

Apple's native AirDrop is strictly restricted to Apple hardware (iPhone, iPad, Mac). Nearbydrop bridges this exact gap by implementing the Android Quick Share protocol on macOS, enabling wireless drag-and-drop transfers with any modern Android device.

Do I need an active internet connection to transfer files?

No. Nearbydrop operates completely offline over your local Wi-Fi network, phone mobile hotspot, or direct USB cable. No data ever touches the cloud or outside servers.

Which Android devices and versions are supported?

Any Android phone or tablet running Android 6.0 or newer with Google Play Services (Quick Share / Nearby Share) or running modern Samsung Galaxy, Google Pixel, Xiaomi, OnePlus, and Motorola devices.

How secure is the transfer?

Nearbydrop uses the UKEY2 cryptographic protocol with elliptic-curve Diffie-Hellman (P-256) handshakes to encrypt data in transit and confirm matching PIN codes on both screens before any data exchange begins.

How do I install the app on macOS?

Download the official Nearbydrop-2.3.0.dmg from GitHub Releases, open it, and drag the app into your Applications folder. Because the app is ad-hoc signed, on first run you can approve it via macOS System Settings → Privacy & Security → Open Anyway.
