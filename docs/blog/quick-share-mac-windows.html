Quick Share Between Mac and Windows

Nearby Drop is a macOS menu bar app that can send and receive files with compatible Windows Quick Share devices. It adds a Mac endpoint to a local Quick Share workflow; the Windows PC uses its own compatible Quick Share client.

Mac to Windows

  1. Connect the Mac and Windows PC to a local network that allows device discovery.
  2. Open Nearby Drop from the Mac menu bar, choose files, and select the Windows PC when it appears.
  3. Accept the transfer in the Windows Quick Share client.

Windows to Mac

  1. Open the compatible Quick Share client on Windows and select the files to send.
  2. Choose the visible Nearby Drop Mac, then review and accept the request in the Mac menu bar app.
  3. Find received files in the download folder selected in Nearby Drop.

What has been tested

Both directions passed in a final Debug test build with one Windows PC. For Windows-to-Mac, the received 65,678-byte test file matched its expected SHA-256 and Nearby Drop showed Transfer Complete. For Mac-to-Windows, the user confirmed arrival and the Mac showed Sent; the Windows file hash was not independently checked.

The v2.3.1 release includes these protocol changes, but the packaged release was not separately device-tested. This verifies one Windows device and one test setup; it does not establish compatibility with every Windows PC, Quick Share version, or network. Nearby Drop runs on macOS only and is not a Windows app.

If discovery fails

Keep both devices on a reachable local network. Guest Wi-Fi, client isolation, firewall settings, or local-network permission can stop devices from appearing. LTE-only phone-hotspot discovery has not been verified. File data transfers directly over the local connection; Nearby Drop does not use a cloud relay.
