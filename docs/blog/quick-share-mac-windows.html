MAC ↔ WINDOWS · QUICK SHARE GUIDE

Quick Share Between Mac and Windows

BY ARSLAN BASHARAT · UPDATED OCTOBER 24, 2026

Nearby Drop is a macOS menu bar app that can send and receive files with compatible Windows Quick Share devices. It adds a Mac endpoint to a local Quick Share workflow; the Windows PC uses its own compatible Quick Share client.

Check Windows Quick Share requirements

  • Google Quick Share for Windows requires 64-bit Windows 10 or later; ARM-based PCs require Windows 11 or later. Samsung PCs should use Samsung's Quick Share app.
  • For Google's Windows client, enable Bluetooth and Wi-Fi or Ethernet, connect both devices to the same network, and keep them within 5 metres (16 feet). Set Windows device visibility so the Mac can find it.

These are Google's client requirements. Nearby Drop is a separate macOS endpoint. See Google's current Windows setup and troubleshooting guidance. This guide's test covers one Windows PC, not every model or network.

Mac to Windows

  1. Connect the Mac and Windows PC to a local network that allows device discovery.
  2. Open Nearby Drop from the Mac menu bar, choose files, and select the Windows PC when it appears.
  3. Accept the transfer in the Windows Quick Share client.

Windows to Mac

  1. Open the compatible Quick Share client on Windows and select the files to send.
  2. Choose the visible Nearby Drop Mac, then review and accept the request in the Mac menu bar app.
  3. Find received files in the download folder selected in Nearby Drop.

What has been tested

Both directions passed in a final Debug test build with one Windows PC. For Windows-to-Mac, the received 65,678-byte test file matched its expected SHA-256 and Nearby Drop showed Transfer Complete. For Mac-to-Windows, the user confirmed arrival and the Mac showed Sent; the Windows file hash was not independently checked.

The protocol changes first shipped in v2.3.1. The current v2.3.4 packaged app has not been separately device-tested for this Windows flow. This verifies one Windows device and one test setup; it does not establish compatibility with every Windows PC, Quick Share version, or network. Nearby Drop runs on macOS only and is not a Windows app.

If discovery fails

Keep both devices on a reachable local network and Bluetooth turned on. In Windows Quick Share, check Device visibility so the Mac can see the PC. Guest Wi-Fi, client isolation, firewall settings, or local-network permission can stop devices from appearing. LTE-only phone-hotspot discovery has not been verified. File data transfers directly over the local connection; Nearby Drop does not use a cloud relay.
